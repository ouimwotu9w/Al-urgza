# 📱 تطبيق «الأَرْجُوزَة»

تطبيق Flutter (Dart) أنيق بتصميم **Material 3** لعرض **أُرْجُوزَةُ المِلَلِ وَالنِّحَلِ** للشاعر **عاصف بن الجمل** — 200 بيت مشكول، مشروحَين شرحاً مفصلاً بيتاً بيتاً، مع معجم مصطلحات واختبار فهم وتتبّع تقدم القراءة.

---

## ✨ الميزات

| الميزة | الوصف |
|--------|-------|
| 📖 **القارئ بوضعين** | بطاقات قابلة للتوسيع، أو قراءة متواصل شبيهة بالكتاب المفتوح |
| 📚 **12 باباً** | المقدمة + المواضيع العشرة + الخاتمة، بألوان وأيقونات مميزة لكل باب |
| 📝 **شرح مفصل** | فقرة شارحة لكل بيت من الأبيات الـ 200 |
| ✨ **بيت اليوم** | بيت جديد كل يوم في بطاقة مميزة بالرئيسية |
| ⭐ **المفضلة** | حفظ الأبيات والعودة إليها |
| 💬 **الملاحظات** | ملاحظة شخصية على أي بيت |
| 🖼️ **المشاركة كصورة** | توليد بطاقة أنيقة بالبيت لمشاركتها (أو نسخ/مشاركة كنص) |
| 🔤 **تلوين القافية** | آخر كلمة من كل شطر بلون الباب |
| 🔍 **بحث شامل** | في الأبيات والشروح والمصطلحات — يتجاهل التشكيل تلقائياً |
| 📖 **معجم المصطلحات** | 23 مصطلحاً من اصطلاحات الأرجوزة بشرح واضح |
| 🧠 **اختبار الفهم** | 10 أسئلة عشوائية من بنك من 28 سؤالاً مع تغذية راجعة وشرح |
| 📊 **تتبع التقدم** | أبيات مقروءة، نسبة إنجاز لكل باب، آخر موضع قراءة يُحفظ تلقائياً |

| 🌙 **وضع ليلي** | حسب النظام / فاتح / داكن |

## 🚀 التشغيل

المشروع يحتوي كود Dart كاملاً (`lib/` + `pubspec.yaml`)، ويولّد Flutter مجلدات المنصات (android/ios...) تلقائياً:

```bash
# 1) أدخل مجلد المشروع
cd al_urjuza

# 2) ولّد مجلدات المنصات (لن يلمس ملفاتك الحالية)
flutter create . --project-name al_urjuza

# 3) نزّل الحزم
flutter pub get

# 4) شغّل التطبيق
flutter run
```

> **ملاحظة**: أول تشغيل يحتاج اتصالاً بالإنترنت لتحميل خطَّي Amiri وCairo عبر حزمة `google_fonts`، وبعدها تُخزَّن محلياً تلقائياً.

### متطلبات البيئة
- Flutter **3.16 أو أحدث** (Dart 3.3+)
- أندرويد / iOS / ويب — يعمل على المنصات الثلاث

## 🎨 تخصيص الهوية البصرية

| ماذا تريد تغييره؟ | أين؟ |
|------------------|------|
| اللون البذري | `lib/theme/app_theme.dart` → `seedBlue` |
| خلفية بطاقة المشاركة | `lib/widgets/share_verse.dart` → `_ShareCard` |
| تدرّجات الرئيسية والقائمة | ابحث عن `0xFF1A237E` في `widgets/` و`screens/` |
| ألوان الأبواب وأيقوناتها | `lib/data/poem_data.dart` |
| خط الأبيات | `lib/theme/app_theme.dart` → `AppTheme.verseStyle` |
| نصوص الشرح | ملفات `lib/data/section_*.dart` → حقل `explanation` |
